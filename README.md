# ENTRE O SILÊNCIO E A CORAGEM

## Leitura do README
Para jogar o jogo, é necessário ter o .NET 10.0 instalado no seu computador. Caso não tenha, siga os passos abaixo para baixar e instalar.

## Como baixar o .NET 10.0?
1. Abra a pasta do projeto "JogoCombateAoBullyingECyberbullying"
2. Abra a pasta "bin"
3. Abra a pasta "Debug"
4. Abra a pasta "net10.0-windowns"
5. Dê dois cliques em "JogoCombateAoBullyingECyberbullying.exe"
6. Irá aparecer uma mensagem para baixar o .NET 10.0, clique em "Download it now"
7. Após baixar, abra o arquivo e clique em "Instalar"
8. Permita que o aplicativo faça alterações no seu dispositivo
9. Após a instalação, abra novamente o arquivo "JogoCombateAoBullyingECyberbullying.exe" e o jogo irá iniciar

## Como abrir o jogo?
1. Baixe a pasta do projeto "JogoCombateAoBullyingECyberbullying" na Área de Trabalho do seu computador
2. Abra a pasta do projeto "JogoCombateAoBullyingECyberbullying"
3. Abra a pasta "bin"
4. Abra a pasta "Debug"
5. Abra a pasta "net10.0-windowns"
6. Cliques com o botão direito em "JogoCombateAoBullyingECyberbullying.exe" e aperte "Copiar como caminho"
7. Na Área de Trabalho, clique no botão direito, selecione "Novo" e depois "Atalho"
8. Cole o caminho copiado e clique em "Avançar"
9. Clique em "Concluir"
10. Abra o atalho criado e o jogo irá iniciar
