# ENTRE O SILÊNCIO E A CORAGEM

## Leitura do README
Para jogar o jogo, é necessário ter o .NET 10.0 instalado no seu computador. Caso não tenha, siga os passos abaixo para baixar e instalar.

## Como baixar o .NET 10.0?
1. Caso não tenha .NET 10.0 instalado
   - **1.1** Dê dois cliques em "JogoCombateAoBullyingECyberbullying.exe"
   - **1.2** Irá aparecer uma mensagem para baixar o .NET 10.0, clique em "Download it now"
   - **1.3** Após baixar, abra o arquivo baixado e clique em "Instalar"
   - **1.4** Permita que o aplicativo faça alterações no seu dispositivo
2. Ou baixe pelo site: https://dotnet.microsoft.com/pt-br/download/dotnet/10.0
   - **2.1** Em Windows, aperte "x64" e ele será instalado
   - **2.2** Após baixar, abra o arquivo baixado e clique em "Instalar"
   - **2.3** Permita que o aplicativo faça alterações no seu dispositivo

## Como abrir o projeto em executável
1. Baixe a pasta compactada do projeto "Executavel_JogoCombateAoBullyingECyberbullying"
2. Crie uma pasta na Área de Trabalho chamada "Entre o Silêncio e a Coragem" e passe tudo o que tem na pasta compactada para ela
3. Dê dois cliques em "JogoCombateAoBullyingECyberbullying.exe"
4. Caso não tenha o .NET 10.0 instalado:
   - **4.1** Aparecerá uma mensagem dizendo que precisa instalar o .NET Desktop Runtime
   - **4.2** Clique em "Download it now"
   - **4.3** Abra o arquivo baixado
   - **4.4** Aperte "Instalar"
   - **4.5** Permita que o aplicativo faça alterações no seu dispositivo
   - **4.6** Após instalar, feche esse arquivo
5. Dê dois cliques em "JogoCombateAoBullyingECyberbullying.exe"
6. Caso apareça uma mensagem dizendo "O Windows protegeu o computador":
   - **6.1** Clique em "Mais informações"
   - **6.2** Clique em "Executar assim mesmo"
   - **6.3** Após isso, o jogo irá abrir


## Botões no jogo
Nas janelas que possuem mais de um botão, utilizar o cursor para escolher e clicar no botão desejado.
Nas janelas que possuem somente um botão, como "Voltar" e "Próximo", pode-se utilizar tanto o cursor quanto as teclas "Enter" e "Espaço" para clicar no botão.
